# Uzbek Inflation Forecasting with ARMA Models

## Project Overview

This project demonstrates a complete time series econometrics workflow for forecasting quarterly inflation in Uzbekistan (2000-2025). Developed as a teaching resource for junior specialists at the Institute for Macroeconomic and Regional Studies.

## Learning Objectives

- Data transformation (CPI → log → inflation)
- Stationarity testing (ADF + KPSS)
- Model identification using ACF/PACF
- Estimation of AR, MA, ARMA models
- Model selection using AIC/BIC
- Residual diagnostics (Ljung-Box, normality tests)
- Forecasting with confidence intervals
